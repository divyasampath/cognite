# 📨 Cognite Messenger Assignment

This project is a take-home assignment for Cognite, aimed at building a simple messenger app using **React** and **TypeScript**.

## 📌 Features

- 📨 Send and view messages in a chat window
- 🧑‍🤝‍🧑 Select a friend to view your conversation with them
- ⏱️ Messages display a timestamp
- 💅 Minimal, clean UI with avatar initials for users

## 🛠️ Tech Stack

- ⚛️ React
- 🟦 TypeScript
- 💨 CSS Modules
- ⚡ Vite (build tool)
